CS 499 Computer Science Capstone

Professional Self-Assessment

A reflection on my growth, technical skills, and development throughout the Computer Science program.

During the program in Computer Science, I have gained not only the technical competencies but also increased my knowledge on how I can solve problems. When I entered the program, my initial focus was on the coding and development of software. However, I gradually understood that the field of computer science is way larger and comprises many other aspects such as communication, problem solving, databases, security, software engineering, and continuous learning.

One of the areas where I have made substantial development has been acquiring the ability to effectively convey technical concepts. During the course of the program, I have been involved in various projects, group discussion sessions, presentations, and written explanations directed to various stakeholders. In the case of CS 499, the code review activity allowed me to analyze an existing application, point out its shortcomings, and explain how I intended to make changes. Additionally, the narratives describing each of the enhancements have helped me acquire this skill.

My skills in problem solving have been improved by algorithms and data structures. The Weight Tracking App I made improved the history screen such that it did more than just show stored data. Through an ArrayList, loop structure, comparison, and computations, I was able to determine the initial weight of the user, the present weight of the user, the total change, average change, and general trend.

Software design and engineering has been another field where I have seen significant development. Though the Weight Tracking App functioned well, there were a lot of improvements needed in the design of the app. I included features such as theme customization, user preference storage, validation improvement, new settings menu, and customized goal weight. By working on the existing project, I learned that software engineering involves more improvement of the code and less writing code from scratch.

The database improvement helped me get an idea of how applications should arrange and keep user information safe. At first all the weight data was kept in one place. Wasn't connected to specific accounts. I modified the SQLite database so that each weight entry is connected to the user who made it. I also included a foreign-key connection. Changed the database actions so that users can only view, edit or remove their own records.

Security became especially important during this enhancement. One of the weaknesses I identified during the code review was that passwords were stored as plain text. I improved this by hashing passwords before storing them and comparing hashed values during login. I also restricted database operations using the logged-in user's ID. These changes helped me understand that security should be considered as part of the design of an application rather than something that is added after development is complete.
