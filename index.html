Selected artifact

Weight Tracking App

The Weight Tracking App was created in CS 360: Mobile Architecture and Programming. The original application allowed users to create an account, log daily weight, view and manage previous records, and receive an SMS notification when a fixed goal weight was reached.

Why this artifact was selected

The project contains interface design, Java application logic, an SQLite database, validation, authentication, permissions, and data display. It provided a strong foundation for demonstrating growth in all three required capstone categories.

Software engineering Themes, settings, navigation, saved preferences, validation, customization, and maintainability
Algorithms Collections, loops, comparisons, progress calculations, and trend analysis
Databases SQLite relationships, foreign keys, user-specific CRUD operations, authentication, and password hashing

Milestone One

Code Review

The code review explains the original application's functionality, evaluates its limitations, and introduces the enhancements completed during the capstone.

  • Original functions: Login, weight entry, history management, SQLite storage, and SMS permission handling.
  • Main findings: Basic interface design, a fixed goal weight and phone number, plain-text passwords, limited analytics, and no separation of user records.
  • Enhancement results: Custom themes, persistent settings, progress analysis, user-specific records, database relationships, and improved password security.
