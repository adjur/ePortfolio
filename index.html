CS 499 Capstone

Weight Tracking App Enhancement

The Weight Tracking App was originally created in CS 360: Mobile Architecture and Programming. The original application allowed users to create accounts, log daily weight, view previous records, and receive an SMS notification when a fixed goal weight was reached.

For my CS 499 capstone, I returned to the project and enhanced it across three areas of computer science: software design and engineering, algorithms and data structures, and databases.

Why I Selected This Project

The application included user interfaces, Java application logic, SQLite storage, authentication, validation, permissions, and data management. This made it a strong project for demonstrating how my skills developed throughout the Computer Science program.

Software Engineering Interface design, themes, settings, navigation, saved preferences, validation, and maintainability
Algorithms Collections, loops, comparisons, progress calculations, and trend analysis
Databases SQLite relationships, foreign keys, user-specific CRUD operations, authentication, and password hashing

Code Review

Reviewing and Improving Existing Software

Before beginning the capstone enhancements, I completed a code review of the original Weight Tracking App. The review examined the application's current functionality, identified weaknesses, and outlined the improvements that would later be implemented.

  • Original functions: Login, weight entry, history management, SQLite storage, and SMS permission handling.
  • Main findings: Basic interface design, a fixed goal weight, plain-text passwords, limited analytics, and no separation of user data.
  • Final improvements: Custom themes, saved settings, progress analysis, user-specific records, relational database improvements, and stronger password security.
