## CS 499 Capstone

For my capstone project, I enhanced a Weight Tracking App originally created in CS 360: Mobile Architecture and Programming.

The application was improved in three areas:

### Software Design and Engineering

* Added customizable themes
* Added saved user preferences
* Improved validation and navigation
* Added a redesigned Settings screen
* Added a customizable goal weight

### Algorithms and Data Structures

* Added progress calculations
* Calculated starting and current weight
* Calculated total and average weight change
* Added upward, downward, and stable trend analysis
* Handled empty and single-entry histories

### Databases and Security

* Connected weight records to individual users
* Added relational database structure and foreign keys
* Restricted CRUD operations by user ID
* Replaced plain-text password storage with password hashing
